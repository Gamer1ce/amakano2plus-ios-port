# 中文游戏功能与使用说明

本说明介绍 R20 普通版移植程序已经实现的界面与操作，不代表每条路线、
每个效果或每台设备都已经完整验收。公开源码需要自行提供合法的完整资源。

## 开始与选择故事

首次启动会要求确认主角姓名、生日和生日陪伴角色。完成设置后，可以从主菜单
选择“开始游戏”，或用“选择故事”进入以下故事入口：

| 角色 | 故事入口 |
| --- | --- |
| 结灯 | 学生纯爱篇、新婚相爱篇 |
| 玲 | 学生纯爱篇、新婚相爱篇 |
| 千岁 | 学生纯爱篇、新婚相爱篇 |
| 咲来 | 学生青春篇、雪国恋爱篇、新婚未来篇 |

点击故事入口会新开当前剧情，切换前请先存档。主菜单“继续存档”进入读档列表。
具体入口是否可用取决于本地剧本目录是否完整。

## 推进对白与自动阅读

- 点击游戏画面推进对白；出现剧情选项后，点击对应选项继续。
- 工具栏的“自动”开启自动阅读，开启后按钮变为“停止自动”。
- 设置中的“自动阅读间隔”范围为 1–10 秒；这是基础等待间隔，实际等待会
  根据对白长度延长，弹出菜单或选项时暂停自动推进。
- 点击“回看”查看当前 VM 中记录的对白和说话人。这里是对白历史，
  不是回退剧情的功能，也没有实现历史语音重播。
- 在 Mac 浏览器预览时，空格和 Enter 可推进对白；编辑姓名等输入框时不会
  用这些按键推进剧情。

普通版没有此前测试版的剧情加速器，也没有提供已读跳过或全剧情扫描按钮。

## 存档与读档

移植版提供 **8 个本机存档位置**，显示保存时间、剧本位置和对白摘要。
请在对白或选项出现、程序完成当前指令后存档；资源读取或画面恢复过程中，
相关按钮会暂时不可用。

读档恢复保存的剧情状态及画面状态。存档属于应用本地数据，卸载应用或清除
其数据可能使存档丢失。当前没有云同步、跨设备迁移、存档文件导入 / 导出界面，
也不保证与 Windows 原版存档格式兼容。

新开局会使用设置中的新姓名；读档时使用该存档里保存的姓名。

## 场景回想与 CG 鉴赏

正常游玩模式按通关和登记进度开放回想与鉴赏：

- **场景回想**：按结灯、玲、千岁、咲来分组，带缩略图和分页。
  可用场景点击后进入回想；未开放场景显示锁定状态。
- **CG 鉴赏**：按角色和分页选择图片，进入后用“上一差分”“下一差分”
  浏览当前 CG 的差分。退出鉴赏会尝试恢复进入前的剧情画面。
- **一键解锁**：在“设置”中开启“解锁全部回想与 CG”，即可浏览完整目录。
  关闭后按真实游玩进度开放。这是可切换的查看权限，不会替你完成故事路线，
  不会补回缺失的素材，也不等于全剧情验收通过。

## 声音与个人设置

音乐、语音、音效、影片音量分别可调，并支持统一静音。若 WebKit 限制或暂停
播放，工具栏会出现“恢复声音”，点击后由程序尝试恢复播放；此按钮不表示
某个具体音频文件已经验证无误。

设置还提供姓名、生日、生日陪伴角色修改，以及体毛、爱心眼和默认 / 内衣 /
裸体显示模式。显示偏好通过原游戏标志参与剧情和画面控制，实际效果取决于
场景是否提供对应素材，并非强制替换所有场景。

## 画面与运行方式

程序使用 Swift 原生容器和 WebKit 运行时，安装完整资源后由应用内的
`game://` 服务读取本地文件，不需要连接 Windows 主机进行串流。
界面按横屏缩放；竖屏浏览器预览会提示横屏效果更佳。

R20 已针对人物、字幕底板和文字的层级调整显示，并修复已发现的滤镜过场
捕获停止以及过场旧字幕残留问题。公开源码另补强了文件路径的符号链接校验，
所以新构建并非原本地 IPA 的字节完全相同副本。

## 签名与设备验收

本地完整 R20 包是未签名 IPA，需要使用自己的签名方式安装；签名有效期以
实际使用的账户和工具为准。公开源码使用 Xcode 构建时，需设置自己的 Team。

项目目标设备是 iPadOS 26；工程最低系统配置不代表所有较旧设备都已验证。
目前已做局部 Mac WebKit 检查和合成单元测试，**签名后的 iPad 实机运行、
全剧情逐条游玩、内存压力和跨版本存档兼容性尚未完整验收**。

遇到错误时，可进入“查看兼容性记录”。提交 GitHub Issue 时提供设备、系统、
构建版本、故事入口和重现步骤；不要上传完整游戏资源、私人存档或签名密钥。
